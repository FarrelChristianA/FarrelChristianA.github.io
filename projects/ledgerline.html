Ledgerline

A personal finance app built around how money actually arrives here: a salary paid on the 25th funds the next month. Type "ayam geprek 25k, grab 18k" and it logs two expenses with their categories. One number tells you what is left to spend today.

The big picture

A personal finance app built around payday. It shows one number, what is left to spend today, and makes logging an expense as quick as typing a message.

The problem

Budget apps assume the month starts on the 1st, and logging every expense is slow.

What it does

Budgets that follow payday, quick add in plain words, a calendar of bills, a year report and six themes.

Where it stands

One HTML file. It runs inside Claude with sync across devices, or in any browser with demo data.

Why I built it2026From the shop counter

At the family shop I handle cash, stock and bills every day, so I see how fast small spending adds up. I wanted the same clarity for my own money, in a form that matches how salaries arrive here: paid on the 25th, funding the next month.

Logging also had to take seconds, or I would stop doing it. So the app reads plain words like "ayam 25k, grab 18k" and sorts them for me.

How I built it

Designed and directed by me. Code written with AI.

I don't have a coding background. I learned to build by directing AI: I decide what the tool must do, write the specs and the rules, review every change and test it until it works. Claude and other AI tools write the code.

  • Specs and rules written before any code
  • Every change checked in the browser before it stays
  • Secrets, personal data and real accounts removed before publishing
The code

Clean code, no keys inside.
