How a project page will read.

This page is an example. It shows the structure every finished case study will follow. The chart uses made-up sample data and is labeled that way.

01 The question

One clear question a reader can answer yes or no to. For example: does a market move more on decision days than on a normal day?

02 The data

Where the data comes from, the date range, and how it was cleaned. Public sources only, each linked at the bottom of the page.

03 The method

The steps in plain words, then the formulas in the Excel file and the SQL queries for anyone who wants to check them.

Sample data for layout only. Not a result.

04 The result

The answer in one or two sentences, with the numbers that support it. If the answer is "no clear difference", the page says exactly that.

05 The limits

  • What the data cannot show.
  • How small the sample is.
  • What would change the conclusion.

06 Sources

Every source with a link and the date it was accessed.
